1 · Sequencer with Line tracks. Each track has a Steps / Line switch. Steps works as it does now, with gates. Line replaces the 16 cells with a lane you draw in, the same as the warp graph. Top is the Dry/wet set on the card, bottom is dry. Clicking a Line track selects it and makes it taller for editing, and the toolbar then shows the warp's tools for that track. The green playhead is the Sequencer's transport. Each track keeps its own length and time scale. Here Voxel is at ½× and runs over 2 bars.

2 · Dice with locks. Lock mode is on (the 🔒 button). Stale's line is locked, so Dice all lines leaves it alone and gives Voxel and Echo 4D new lines. Step tracks are never touched by line dice; they keep using the existing Random button. Quantize and Skew are per track. Locks are a UI preference saved on this machine only, the same as the warp's locks.
